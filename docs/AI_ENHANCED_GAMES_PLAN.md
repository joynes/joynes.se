# Faithful AI Enhanced editions

AI Enhanced restores each original game while keeping its gameplay, maps, controls, physics, progression and identity. Prefer the same gameplay engine where possible. Improve graphics, clarity and audio without turning it into a different game. Use Blender for reproducible graphics and preserve original sound/music when they carry the game's identity. Keep assets, records, provenance and browser test evidence separate.

Expose available editions directly in the homepage game picker. Original launches the web restoration. AI Enhanced launches the faithful restored edition. Remix identifies a reimagining with new rules, levels or missions. Publish an edition only after actual gameplay, touch, physical keyboard, cancellation/focus/restart, fullscreen and recovery tests pass. Work one game at a time and commit source in its existing private repository before publishing.
