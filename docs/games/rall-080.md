# Rall v080 — Fighters

The original Windows fighting logic now compiles to WebAssembly: thirteen original C++ gameplay files, with a browser adapter for graphics, configuration, fonts and audio. The Drive folder is v080; its readme identifies 0.0081. The archived executable, gameplay source and media match the local originals. Original archives and the keyboard-only probe remain private in the existing repository. [Restoration notes](../../games/rall-080/source-notes.md) · [Asset provenance](../../games/rall-080/provenance.json).

Solo progression and first-to-two local duels are playable. Native punch/kick/throw, blocking, jumps, crouching, knockdowns and round introductions are retained. The short English host adds in-scene touch controls, both keyboard profiles, pause/restart, records and fullscreen. Native fullscreen works in Chromium. When a browser rejects it, a checked same-origin bridge expands the same iframe into the whole page without reloading the fight; fullscreen exit and Menu restore its layout.

Local tests pass both players' complete matches and real AI victory/progression/loss/replay in desktop keyboard and portrait/landscape native touch. Both teams' close-combat throws, punches and blocking were verified. Chromium and installed Chrome input tests cover four viewports down to 320px; frame tests include short 568x320. Eighteen representative critical-load failures recover to real combat, and denied storage/failed music are nonfatal. Original source and exported/compiled hashes are verified. The original engine rebuild is byte-identical.

These are automated browser tests with emulated mobile contexts; physical devices and Safari are not covered. Canonical homepage launch passed all three viewports in Chromium (native fullscreen) and installed Chrome (full-page fallback), including native touch attacks and top-level return. The forwarding fixture and Rall054 navigation regression also passed. The published release passed all live suites: nine full gameplay cases, two advanced combat cases, four input and four frame cases in each browser, nineteen recovery cases, and three navigation cases on each public entry point in each browser. All 236 published files match their release hashes. [Play the original restoration](https://joynes.github.io/joynes.se/games/rall-080/).
