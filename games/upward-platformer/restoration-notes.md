# Upward Platformer browser audit · 2026-11-05

Working title; the original project is archived as `game`. Original desktop/common source and media were checkpointed before browser work. `SOURCE_MANIFEST.json` records all 22 recovered files. Original code and media remain unchanged.

Passed `scripts/test-browser.cjs` in installed Chrome at 1280×900, 390×844, 844×390 and 320×740. Actual keyboard movement and jumping worked together in each touch-enabled viewport. Native Chrome touch events held movement and jump simultaneously, retained jump after independently lifting movement, and cleared contacts on cancellation. Keyboard release cleared native direction; ordinary enemy knockback remains part of the original physics. Pause froze native frames. A browser blur event cleared inputs and paused; this is not a claim about physical OS window switching. Restart blocked a still-held key and restored the original initial player, platforms and enemies. Fullscreen entry/exit, rotation, attached-keyboard ownership through rotation, mute and day/night switching passed. No physical handset or WebKit browser was tested.

Passed `scripts/test-gameplay.cjs`: ordinary keyboard jumping landed on platforms, increased native height, moved the following camera, survived a fall without runtime errors, restored the complete initial course/player state on restart, and retained best height across reload. Read-only native snapshots checked gameplay beyond menus. Mobile screenshot inspected for the original art, height display and controls inside the view. This does not establish completion of all 10,000 platforms; unsuccessful advanced-climb pilots are retained privately in `experiments/`.

Passed `scripts/test-recovery.cjs`: aborted script, WebAssembly, graphics package and WAV effect each exposed Retry, then loaded the real game after recovery. Restart blocked stale keys; fullscreen/rotation retained active physical-key ownership. Actual WebGL context loss exposed Retry. Failed music did not block play; the sound button reloaded it. Testing found that a media error could occur before the script registered its listener; checking the media element’s existing error fixes recovery. All five archived effects decoded; original music played in a normal browser smoke test.
