Keyboard and touch controls

Blue tank: arrows drive and turn, I / O rotate the gun left / right, P fires, U toggles siege mode.

Green tank: D / X drive, Z / C turn, B / N rotate the gun left / right, V fires, M toggles siege mode.

The original help image swaps the tank colours. Use the bindings above.

In siege mode, direction controls adjust aim and power. W pauses; Enter continues when prompted. Tab opens the original console. Shift+Tab returns focus to the toolbar. Touch buttons support holding movement and firing together.

Changing the mode restarts the original game. This avoids its documented computer-opponent issue when switching from single player to two players.
