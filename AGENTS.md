# Website development requirements

- Write all new user-facing text, help, documentation and progress messages in English.
- Keep all website interface text entirely in English and concise, including menus, game labels, buttons, descriptions and help.
- Every game must support mobile touch and a physical keyboard, including a keyboard attached to a phone or tablet.
- Every real-time game must provide touchscreen controls for every gameplay action, including simultaneous movement and actions such as firing or jumping.
- Put touch controls inside the game view as overlays, never in a button row below the game. Provide a visible fullscreen control usable by touch and keyboard; verify fullscreen entry/exit and usable controls in both orientations.
- Verify both input methods through the actual browser interface. Check simultaneous controls, key release, touch cancellation, lost focus and restart.
- Work on one game at a time, test before publishing, and commit changes.
- Finish the incomplete rall0054, v080 and rall008 adaptations. Their archive links do not count as playable web releases.
- Verify game launch and fullscreen through joynes.se as well as the direct Pages URL; its forwarding frame does not delegate fullscreen.
- Keep the publication inventory accurate. A successful build or a visible menu alone does not establish that a game works.

# AI Enhanced editions

- After the current fixes, create a new AI Enhanced edition of each adapted older game, one game at a time.
- Use new gameplay ideas, Blender graphics and ElevenLabs sound/music through the available skills.
- Offer Original / AI Enhanced at launch once the enhanced edition is playable and verified. Preserve the restored edition and keep saves and assets separate.
